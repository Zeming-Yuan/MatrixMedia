# 视频分发操作指南

本文介绍在 Windows 上使用矩媒 MatrixMedia 添加账号、上传视频、选择发布平台、查看结果及批量分发的操作。全程通过软件界面完成，无需使用命令行。

操作顺序：**打开软件 → 添加并登录账号 → 选择视频 → 填写内容 → 勾选账号 → 发布或保存草稿 → 核对结果**。

首次操作时，先用一个视频、一个账号完成整个流程，再增加目标账号和视频数量。

## 1. 安装并打开软件

1. 获取团队提供的 Windows 安装包，例如 `MatrixMedia-0.14.7-rc.1-win-x64.exe`。
2. 双击安装包，按安装窗口提示完成安装。
3. 如需选择安装位置，使用独立目录，例如 `D:\Apps\MatrixMedia`。当前内部版本优先使用不含中文和空格的安装目录，不要选择项目源码目录。
4. 安装完成后打开“矩媒”。如果没有桌面快捷方式，进入安装目录，双击 `matrixmedia.exe`。

准备好要发布的视频文件、标题、简介，以及对应平台的账号和用于扫码登录的手机。可以先使用能在电脑上正常播放的 `.mp4` 视频；是否符合上传要求，以各平台页面提示为准。

账号登录状态和发布记录保存在使用的电脑上。其他电脑使用时，需要分别添加并登录账号。

## 2. 添加发布账号

点击软件右上角的 **“添加媒体账号”**，填写以下信息：

| 项目 | 填写方式 | 示例 |
| --- | --- | --- |
| 分组 | 用于整理账号，可以选择已有分组，也可以输入名称后按回车新增 | 公司官方账号 |
| 账号名称 | 填写方便辨认的名称；留空时默认使用分组名称 | 公司抖音主号 |
| 平台 | 选择该账号所属的平台 | 抖音 |

填写后点击 **“新增”**。分组名称不需要填写真实手机号，也不是平台登录密码。

同一分组可以添加多个平台、多个账号。不同的实际账号请使用不同的账号名称；同一平台的同名账号跨分组会共享登录状态，只有确实是同一个账号时才这样设置。

## 3. 登录对应平台

1. 点击顶部 **“媒体平台管理”**。
2. 在左侧选择要登录的账号，核对页面上的分组、账号和平台。
3. 点击 **“打开登录窗口”**。部分情况下，选择账号后会自动打开登录窗口。
4. 在弹出的平台页面中扫码，或使用该平台提供的其他登录方式。
5. 登录后核对页面显示的账号，确认没有登录到其他账号。
6. 如果出现引导、协议确认或提示弹窗，先按平台要求处理，再返回矩媒。

视频号页面另外提供 **“使用 Chrome 登录”**。如果内置窗口扫码后提示没有可登录的视频号，可以尝试此入口；电脑需要已安装可用的 Chrome。

账号需要具备对应平台的发布权限。登录过期后，回到这个页面重新登录即可。没有团队指定配置时，“发布代理”可以先留空。

## 4. 设置发布方式

在对应账号页面找到 **“发布设置”**。

如果页面显示 **“默认发布到草稿”**：

| 使用目的 | 设置方式 |
| --- | --- |
| 希望直接提交发布 | 关闭“默认发布到草稿”，点击“保存发布设置” |
| 希望先保存，再由人员检查 | 开启“默认发布到草稿”，点击“保存发布设置” |

**账号开启默认草稿后，即使最后点击“发布”，也会优先保存到草稿。**多账号任务中，每个账号的设置可能不同，需要分别确认。

小红书账号页面提供“使用真实浏览器”设置。如需启用，选择或自动检测本机 Chrome，点击 **“测试连接”**，确认可用后点击 **“保存发布设置”**。小红书发布过程会保留窗口，方便查看结果或处理平台确认；此设置不代表平台一定接受本次发布。

## 5. 选择视频并填写发布内容

点击顶部 **“视频管理” → “选择视频发布”**，在文件选择窗口中选中一个视频。

在 **“填写发布内容”** 窗口填写：

| 字段 | 用途与填写说明 | 示例 |
| --- | --- | --- |
| 名称 | 用于在软件中辨认这份素材，默认与视频文件名一致 | 公司介绍第一版 |
| 视频标题 | 发布时使用的标题，需要填写 | 一分钟认识我们的团队 |
| 视频简介 | 视频正文或简介，按内容填写 | 介绍我们的团队、产品与日常工作。 |
| 视频标签 | 输入一个标签后按回车添加，也可以批量粘贴带 `#` 的标签 | 团队日常、公司介绍 |
| 视频号短标题 | 仅视频号使用，填写时按界面要求控制在 6～16 字，避免特殊标点 | 一分钟认识我们的团队 |
| 封面图片 | 选填。界面注明抖音、快手、视频号使用自定义封面；视频号封面使用 jpg/png | 选择准备好的封面文件 |
| 定时发布 | 立即操作时保持“立即”；需要预约时再开启 | 立即 |

不选择封面时由平台自动截取视频帧。AI 生成按钮是可选功能，手动填写内容不需要配置 AI 服务。

确认内容后点击 **“下一步”**。

## 6. 勾选发布账号

进入 **“选择账号并发布”** 窗口后：

1. 展开分组，勾选准备接收这个视频的平台账号。
2. 点击分组旁的 **“验证登录”**，查看账号登录状态。
3. 如果显示 **“❌重新登录”**，点击它完成登录后再继续。
4. 首次操作可将 **“是否显示自动化发布过程”** 设置为“显示”。
5. 将 **“发布完是否关闭窗口”** 设置为“不关闭”，方便核对页面结果。
6. 若账号下方出现创作声明，按视频实际内容选择。例如包含 AI 生成内容时，选择对应的 AI 声明。也可以使用“批量声明”和“应用到已勾选”，再逐一检查。
7. 点击 **“下一步”**。

第一次只勾选一个账号。完成整个流程并确认结果后，再同时勾选多个账号。

## 7. 发布或保存草稿

接下来会显示 **“确认发布账号”** 或 **“设置第三方属性”** 窗口，具体标题取决于所选平台。

普通视频的第三方属性保持 **“无”**。只有确实需要挂载商品、短剧或剧集时，才填写相应内容；这些操作还需要对应平台权限。

最后核对目标账号，再选择按钮：

| 按钮 | 操作含义 |
| --- | --- |
| 发布到草稿 | 上传并尝试保存为平台草稿，不代表已经公开发布 |
| 发布 | 执行发布流程；账号若开启“默认发布到草稿”，仍会优先保存草稿 |

点击一次后等待。上传过程中保持网络连接和软件运行，不要移动或删除正在使用的视频文件。

**“已提交几个平台发布”表示任务已经开始，不是发布成功通知。**不要因此连续点击发布，也不要在结果不明确时直接重发。

## 8. 查看结果

回到 **“视频管理”**，找到刚才的视频，分别查看每个平台的状态。

| 状态 | 含义 | 接下来做什么 |
| --- | --- | --- |
| 发布中／保存草稿中 | 任务仍在执行 | 等待，不要重复提交 |
| 成功 | 软件本次发布流程返回成功 | 到平台作品管理中核对；公开状态以平台后台为准 |
| 已保存草稿 | 草稿保存流程返回成功 | 按需到平台查看或继续处理，不要当作已经公开发布 |
| 等待确认 | 平台仍需要扫码、安全确认或其他处理 | 查看平台窗口并处理，再核对后台结果；任务已结束时不要默认它会自动继续 |
| 需重新登录 | 当前登录状态无法继续使用 | 回到“媒体平台管理”重新登录 |
| 失败／发布异常 | 本次任务未正常完成 | 若失败或异常次数可点击，打开截图查看原因 |
| 等待定时发布 | 已创建本机定时任务 | 到点时保持电脑开机、程序运行、网络正常 |
| 任务过期 | 错过了本机定时执行时间 | 核对平台后，再决定是否重新安排任务 |

有 **“获取状态”** 按钮的记录可以点击刷新平台状态。如果需要保存操作记录，可以点击 **“导出当前记录”**。

结果不明确时，先到平台后台查找是否已有相同视频。确认没有重复内容、并处理完错误原因后，再使用 **“重新发布”**。

## 9. 将同一个视频分发到多个账号

1. 按前面的步骤，分别添加并登录目标账号。
2. 在“视频管理”中选择视频并填写内容。
3. 在“选择账号并发布”窗口勾选多个目标账号，核对各账号的登录状态和创作声明。
4. 确认每个账号的默认草稿设置符合本次目的，再提交任务。
5. 在发布记录中分别核对每个平台的结果。

一次勾选多个账号后，软件会向这些账号分别提交任务。某个平台成功，不代表其他平台也已经完成。

## 10. 批量发布多个视频

目录批量发布需要准备 **视频文件夹** 和 **Excel 声明文件**。声明文件用于填写每个视频的标题、简介等信息，只选择文件夹不能完成下一步。

1. 把本次准备发布的视频放到一个文件夹，例如 `D:\Videos\Team`。
2. 点击 **“视频管理 → 目录发布”**。
3. 点击 **“下载模版”**，用 Excel 或 WPS 打开下载的表格。模版通常位于系统“下载”文件夹，文件名为 `batch-publish-template.xlsx`。
4. 替换模版中的示例数据，每一行对应一个视频；没有使用的示例行请删除。
5. 保存为 `.xlsx` 文件。
6. 回到矩媒，点击 **“选择目录”**，选择视频所在文件夹。
7. 点击 **“选择声明文件 (xlsx)”**，选择刚保存的表格。
8. 核对预览内容后点击 **“下一步”**。软件会校验表格中的视频文件是否存在，找不到时会提示并停止继续。
9. 选择目标账号，核对声明和发布方式，再点击“发布”或“发布到草稿”。

表格示例：

| 文件名 | 标题 | 简介 | 标签 | 视频号短标题 | 封面 |
| --- | --- | --- | --- | --- | --- |
| video01.mp4 | 一分钟认识我们的团队 | 团队与工作介绍 | 团队日常,公司介绍 | 一分钟认识我们的团队 | |
| video02.mp4 | 记录团队的一天 | 展示一天的工作片段 | 团队日常,工作记录 | 记录团队工作的一天 | |

“文件名”建议填写带扩展名的完整名称，并与文件夹里的文件对应。“封面”可以留空；填写时可以使用图片绝对路径，也可以使用相对于视频目录的路径，无效路径会阻止发布。

首次批量操作先使用少量视频，完成并核对结果后，再增加数量。

## 11. 定时发布

在填写发布内容或目录批量发布时，将“定时发布”切换为 **“定时”**，选择未来的发布时间，然后继续选择账号并提交发布任务。

这是在当前电脑上执行的定时任务。到点时需要电脑开机且不处于睡眠状态、矩媒保持运行、网络可用。关闭软件后错过执行时间的任务会显示“任务过期”。

“发布到草稿”不支持定时发布。需要保存草稿时，关闭定时设置；需要定时正式发布时，也要确认各账号没有开启默认草稿。

## 12. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 点击“发布”后只有草稿 | 检查对应账号的“默认发布到草稿”是否开启，修改后点击“保存发布设置” |
| 没有可选择的账号 | 先通过右上角“添加媒体账号”新增账号，再打开发布窗口 |
| 提示需要登录 | 选择正确账号，打开登录窗口，完成登录后重新验证 |
| 登录后出现引导或提示挡住页面 | 在平台窗口中按提示完成或关闭，再继续操作 |
| 显示等待确认 | 查看平台窗口，完成必要确认，并到后台核对结果；不要反复提交同一个视频 |
| 批量发布找不到文件 | 检查声明文件中的文件名、扩展名和所选目录，删除未使用的模版示例行 |
| 任务失败但原因不明确 | 查看可点击的失败／异常次数及截图，将提示内容交给维护人员排查；反馈前遮挡账号等个人信息 |
| 没有桌面快捷方式 | 进入实际安装目录，运行 `matrixmedia.exe` |

本文按当前软件界面整理。各平台的实际投稿结果需分别核对；当前内部版本的实测范围见 [Windows 0.14.7-rc.1 验收记录](./windows-0.14.7-rc.1-acceptance.md)。
